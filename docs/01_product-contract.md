# 《创作星球》V2 产品合同

状态：核心口径已确认，页面细节随阶段验收继续冻结

## 1. 产品定位

《创作星球》是一款手机端优先的个人创作陪伴工具。它帮助用户保护创作时间、进入创作状态、持续推进多个作品并完成周复盘。

它不是严格考勤工具，也不通过连续打卡或惩罚制造压力。它提供的是温柔但清晰的创作边界。

## 2. 核心用户任务

用户打开应用后，应能快速完成以下事情：

1. 看见本周距离创作目标还有多远；
2. 知道当前作品下一步要做什么；
3. 在少量操作内开始一次创作；
4. 中途暂停并在回来后继续；
5. 结束时留下成果、下一步和进入状态；
6. 回看本周时间投入和作品推进；
7. 调整下一周的创作边界。

## 3. 核心目标

- 每周创作节点目标：4 个；
- 每周创作时长目标：14 小时；
- 两个条件同时达到，才显示本周达标；
- 健身单独记录和展示，不计入创作时长。

## 4. 核心页面

### 首页

- Hero 与鼓励语；
- 本周节点、创作时长、健身与总体达标状态；
- 当前项目和下一步；
- 开始/继续创作入口；
- 上次离开时；
- 本周七天计划；
- 最近创作记录。

### 项目

- 查看全部项目；
- 新建项目；
- 编辑项目名称、阶段和下一步；
- 切换当前项目；
- 归档项目；
- 查看项目累计投入和最近记录。

### 记录

- 开始、暂停、恢复和结束计时；
- 手动补录；
- 查看最近记录；
- 编辑记录；
- 删除记录时必须二次确认。

### 计划

- 查看本周七天计划；
- 修改每天的类型、时间、节点属性和备注；
- 保留默认周计划；
- 计划是边界，不是考勤。

### 复盘

- 本周节点、时长和达标状态；
- 创作类型分布；
- 项目投入分布；
- 本周成果；
- 下周最重要的作品增量。

## 5. 已确认的视觉方向

- 柔和水彩；
- 梦幻、诗意、安静；
- 小王子气质；
- 星空、星球、玫瑰与花野；
- 克制、留白、文艺；
- 不幼稚卡通化；
- 不采用商业科技风；
- 视觉效果不得牺牲实际使用和文字可读性。

## 6. 已确认产品决策

1. 建立独立 V2，在不影响 V1 线上版本的前提下重建基础；
2. 创作节点按实际创作日计算，同一自然日最多 1 个，不要求必须是计划日；
3. 计划完成与实际创作节点分别展示，不再混用同一口径；
4. 周计划和周复盘从 V2 第一版开始按自然周保存历史。
