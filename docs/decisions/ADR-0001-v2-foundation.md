# ADR-0001：建立独立 V2 基础

状态：已确认  
日期：2026-08-30

## 决策

保留 V1 原型和当前线上版本，建立独立 `v2-foundation` 分支。

V2 采用 React、TypeScript、Vite、Zustand、Dexie/IndexedDB、Vitest 与 vite-plugin-pwa，优先实现数据可靠性、计时状态机、旧数据迁移和自动测试。

## 原因

V1 已经通过多层 CSS 覆盖和大量视觉补丁累积了较高回归风险，同时缺少暂停/恢复、记录管理、按周历史、数据迁移、PWA 注册和自动测试。原地继续扩展会让视觉问题与功能问题相互干扰。

## 约束

- V1 在 V2 验收前保持可访问；
- V2 最终仍部署到 GitHub Pages；
- 不引入账号、云同步和多人协作；
- 已确认的产品文案、默认项目、默认周计划与视觉方向继续有效；
- 未通过核心闭环、数据恢复和 iPhone 真机验收前，不替换稳定版本。
