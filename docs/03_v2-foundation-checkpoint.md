## 3. 本轮未通过/待人工确认项

- 云端浏览器被当前运行环境阻止访问本地预览，因此本轮没有把浏览器主流程标记为通过；这不是已发现的产品代码错误。
- 375/390/393/402 像素宽度的真实视觉回归仍需在可访问预览环境中执行。
- iPhone 真机安装、锁屏 40 分钟恢复、首次联网后离线打开仍属于发布前验收项。
- 首页 Hero 当前使用仓库内有效旧素材作为占位，不是最终视觉金标准。

## 4. 当前发布判断

V2 已达到“工程底座可评审”状态，但尚未达到“替换 V1 正式发布”状态。进入正式发布前，必须完成浏览器主流程、视觉金标准和 iPhone 真机验收，并由用户确认合并上线。

## 5. 回滚点

- V1 继续由 `main` 分支提供线上服务；
- V2 位于独立 `v2-foundation` 分支；
- 未修改现有 GitHub Pages 正式入口，出现问题时无需回滚线上版本。
