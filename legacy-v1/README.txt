创作星球 · 手机测试版
1. 直接体验：打开“创作星球_手机测试版.html”即可测试全部按钮与本地记录。
2. 当前数据保存在浏览器 localStorage。
3. 测试版核心功能：
   - 自定义顶部鼓励语
   - 多项目、新建项目、切换当前项目
   - 开始/结束计时，记录创作类型、成果、下一步、进入状态
   - 手动补录
   - 七天计划全部可改类型、时间、是否计入创作节点
   - 周目标：4个创作节点 + 累计创作>=14小时
   - 健身单独显示与统计
   - 周复盘：创作类型、项目投入、成果与下周目标
4. PWA 文件夹版本可部署到 GitHub Pages，部署后 Safari → 分享 → 添加到主屏幕。
